# Scene Finder

Chạy `pip install -r requirements.txt` và `streamlit run app.py`.

Trong tab Phân bố & thuộc tính, chọn Weather = unknown và Time of day = unknown để tìm ảnh khớp cả hai điều kiện. Có thể xem ảnh nếu ZIP có ảnh gốc, tìm theo tên, phân trang và xuất CSV. unknown khác missing. Không tự sửa tag CVAT.
